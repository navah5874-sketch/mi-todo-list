# lista de tareas 

Aplicacion web simple para gestionar tareas pendientes construida con html, css y js.

## caracteristicas 

- agregar tareas desde un formulario
- marcar tareas completadas (click sobre el texto)
- eliminar tareas
-contador de tareas

## tecnologias

- HTMLS
- CSS3
- JavaScript (DOM Y eventos)

## como ejecutarla 

1. Clona el repositorio 

    git clone https://github.com/navah5874-sketch/mi-todo-list.git
2. Abre `index.html` en el navegador o usa la extension **live server**
